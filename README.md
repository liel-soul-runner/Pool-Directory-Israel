# מאגר הבריכות – אתר אנשי מקצוע לבריכות בנויות בישראל

אתר סטטי (HTML, CSS ו-JavaScript בלבד): ללא שלב בנייה, ללא התקנת חבילות וללא תלות בשרת. לכן הוא עולה ל-GitHub ול-Vercel בלי שגיאות.

## מה יש באתר
- שורת חיפוש במסך הפתיחה: טקסט חופשי (מוצר, שירות, עיר), סוג בעל מקצוע ואזור. החיפוש מתעלם מניקוד וצורות רבים/יחיד.
- סינון לפי מחיר מקסימלי, מחיר כולל התקנה, שירות ארצי, ותק ומיון.
- בכל כרטיס: תיאור העסק, ותק, שירותים, אזורי שירות, מחירון (עם סימון כולל התקנה או לא), טלפון, אימייל, כתובת, וואטסאפ, מפה ו-Waze.
- סימון כמה בעלי מקצוע ושליחת אותה בקשת הצעת מחיר לכולם בוואטסאפ.
- כתובת האתר שומרת את החיפוש, כך שאפשר לשתף תוצאות.
- טופס "הצטרפו למאגר" שנשלח אליכם בוואטסאפ.

## חשוב: קבוצת וואטסאפ
וואטסאפ אינו מאפשר ליצור קבוצה אוטומטית מקישור או מאתר. לכן האתר מציע שליחת הודעה זהה לכל אחד מהנבחרים, והעתקת כל המספרים כדי ליצור קבוצה ידנית באפליקציה.

## נתוני הדוגמה
10 הרשומות בקובץ `data/professionals.json` הן **דוגמאות בדויות** (מספרי טלפון בדויים, מסומנות "נתוני דוגמה"). מחקו אותן והוסיפו אנשי מקצוע אמיתיים, רצוי רק בהסכמתם.

## הוספת אנשי מקצוע
1. ערכו ישירות את `data/professionals.json`, או
2. נהלו טבלה ב-Google Sheets, ייצאו ל-CSV והריצו: `node tools/csv-to-json.mjs pros.csv` (דורש Node 18+). הכותרות ופורמט העמודות מופיעים בראש הקובץ `tools/csv-to-json.mjs`.

מזהי הקטגוריות והאזורים מופיעים בראש `data/professionals.json`.

## הגדרות
בקובץ `js/config.js`: מספר הוואטסאפ שלכם לקבלת בקשות הצטרפות ונוסח הודעת ברירת המחדל.

## הרצה מקומית
האתר טוען את הנתונים עם `fetch`, ולכן יש להריץ שרת מקומי ולא לפתוח את הקובץ ישירות:
`npx serve .` או `python3 -m http.server 8000` ואז http://localhost:8000

## העלאה ל-GitHub ול-Vercel
1. צרו מאגר חדש ב-GitHub והעלו את כל הקבצים: `git init && git add . && git commit -m "init" && git branch -M main && git remote add origin <כתובת המאגר> && git push -u origin main`
2. ב-Vercel: Add New, Project, בחרו את המאגר.
3. השאירו Framework Preset על **Other**, ובלי Build Command ובלי Output Directory. לחצו Deploy.
4. לחיבור דומיין: Settings, Domains.

## שיפורים מומלצים להמשך
- שמירת הנתונים במסד (למשל Supabase) ועמוד ניהול לאישור בעלי מקצוע חדשים.
- דפי פרופיל נפרדים לכל בעל מקצוע לצורכי קידום אורגני בגוגל.
- דירוגים וחוות דעת מאומתות.
- ניתוח כניסות ולחיצות על כפתורי וואטסאפ, כדי להציע לבעלי מקצוע חבילות קידום.

## פרטיות
פרסום פרטי עסק של אדם (טלפון, כתובת) דורש בדרך כלל הסכמתו, ויש לכבד בקשות הסרה. מומלץ לעיין בדיני הגנת הפרטיות ובחוק הספאם לפני פנייה יזומה לבעלי מקצוע.
